## 💎 Key Features

### 📊 Advanced Analytics Dashboard
- **Real-time KPIs**: Monitor active vehicles, drivers, and safety scores.
- **Utilization Charts**: Visualized monthly fleet usage using modern data rendering.
- **Activity Stream**: live updates on vehicle check-ins and maintenance alerts.

### 🚗 Intelligent Fleet Inventory
- **Real-time Status**: Track vehicle availability (Maintenance, On Trip, Available).
- **Search & Filter**: Blazing fast search capabilities for large fleets.
- **Dynamic Assets**: Add and manage vehicles with detailed technical specs.

### 👥 Professional Driver Management
- **Personnel Profiles**: Detailed driver cards with licensing and performance tracking.
- **Auto-Status**: Visual cues for driver online/offline states.

### ⛽ Fuel & Expenditure Tracking
- **Consumption Logs**: Monitor fuel liters, costs, and vendor locations.
- **Economy Analysis**: Track spend patterns to optimize fleet efficiency.

### 🔧 Proactive Maintenance logs
- **Service History**: Complete audit trail of past maintenance actions and costs.
- **Fleet Health**: Automatic flags for urgent service requirements.

## 🚀 Getting Started

### 1. Prerequisites
- Node.js (v18+)
- Supabase Account (Optional for Demo Mode)

### 2. Installation
```bash
git clone https://github.com/Jaydip212/DriveControl-Premium-Vehicle-Management.git
cd DriveControl-Premium-Vehicle-Management
npm install
```

### 3. Demo Mode (Immediate Access)
No configuration required! Simply launch the project and use the following credentials to explore the premium UI:
- **Email/User**: `admin`
- **Password**: `admin`

```bash
npm run dev
```

### 4. Supabase Setup
For full database functionality, create a `.env` file and add your credentials:
```env
VITE_SUPABASE_URL=your_project_url
VITE_SUPABASE_ANON_KEY=your_anon_key
```

## 📐 Architecture

The project follows a modular Single Page Application (SPA) architecture:
- **`src/main.js`**: Core routing, state management, and view rendering.
- **`src/style.css`**: Centralized design system with CSS utility tokens and mesh gradients.
- **`src/lib/supabase.js`**: Modular database and auth configuration.
